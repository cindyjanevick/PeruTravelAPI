Peru Travel Guide
A dynamic travel guide website to explore various cities in Peru, with features such as a travel planner, daily travel phrases, restaurant recommendations, and a list of attractions. The website dynamically loads content using external APIs and local JSON files.

Introduction
The Peru Travel Guide is an interactive platform to help travelers plan their trip to Peru, providing information on various cities, popular restaurants, attractions, daily phrases in Spanish, and even Quechua. The website is built using HTML, CSS, and vanilla JavaScript, with dynamic elements loaded from local JSON files and external APIs.

Features
Dynamic City Information: Information on popular cities like Cusco and Puno, including top attractions, restaurants, and local recommendations.

Travel Planner: Plan your trip with start and end dates, trip name, and additional notes saved in the local storage.

Daily Travel Phrase: A randomly generated phrase of the day to help users learn useful phrases in Spanish and Quechua.

Attraction and Restaurant Filters: Filter restaurants and attractions by cost, length, or other criteria for easy planning.

Technology Stack
HTML: Structuring content and page layout.

CSS: Styling with a focus on responsive design.

JavaScript: For dynamic functionality, including form handling, local storage, and API calls.

External APIs:

GeoNames API for city and location data.

ExchangeRate API for currency conversion.

How to Use
Visit the Homepage: Get started by exploring city-specific recommendations.

Explore Attractions and Restaurants: Use the filter options to view top-rated places in each city.

Use the Travel Planner: Create and save your travel plans with trip names, dates, and notes.

Learn Daily Phrases: Get a new phrase in Spanish and Quechua every day to help you communicate better during your travels.
